# 《STL源码剖析》共享术语词典

用于读源码和能力卡，不取代完整C++标准库规范。所有页码均为用户PDF的物理页；历史实现的参数与布局不得自动推广到现代库。术语定义为本项目原创解释，短引文及提取证据另存于候选记录。

## 01. 前闭后开区间 [first,last)

操作范围含first而不含last；first==last表示空区间，必须能从first按所需操作到达last。

**容易混淆：** last不是最后元素；不要解引用end；这里的可达不是要求所有迭代器都支持last-1。

**原书位置：** §1.9.5、§6.1.5，PDF73、330。

## 02. 空间配置器 allocator / SGI alloc

原书把取得储存和建立对象分工；SGI alloc以字节处理底层储存，再经simple_alloc转成元素数量接口。

**容易混淆：** SGI alloc不是标准allocator<T>的可移植替代；不能把allocate理解成new T[n]。

**原书位置：** §2.2.2–2.2.4，PDF84–89。

## 03. 构造与析构 construct / destroy

construct在已有合适储存上构造对象，destroy结束对象生存期；储存是否释放另有步骤。

**容易混淆：** 析构对象不等于释放其储存；已有容量也不等于容量中每个位置都存在对象。

**原书位置：** §2.2.3，PDF85–88。

## 04. 内存池 memory pool

向底层较大批量取得储存，再切出适当规格小块供客户及free-list使用。

**容易混淆：** 它不是客户当前已使用小块的集合；池中未分出部分和free-list中的空闲块需要分别核算。

**原书位置：** §2.2.6–2.2.10，PDF95、102–104。

## 05. 自由链表 free list

按小区块规格维护的可复用空闲块链；申请从对应链取出，归还挂回。

**容易混淆：** 它不是容器list；原书16个规格及8字节步长属于所述SGI实现。

**原书位置：** §2.2.6–2.2.9，PDF95–102。

## 06. 未初始化内存算法

uninitialized_copy/fill/fill_n在未构造的目标储存中建立对象，需处理部分构造失败。

**容易混淆：** 普通copy针对既存目标赋值；不能用一个写入动作概括构造与赋值。

**原书位置：** §2.3，PDF106–108。

## 07. 迭代器 iterator

对遍历、访问和可支持操作的一组约定，使算法不必了解容器储存布局。

**容易混淆：** 迭代器不必是原生指针；随机存取也不说明内存连续。

**原书位置：** §3.1–3.2，PDF116–117。

## 08. 相应型别 associated types

与迭代器相关联的value_type、difference_type、pointer、reference、iterator_category等型别信息。

**容易混淆：** 这些不是运行时对象值；reference与value_type也不应直接混为同一种东西。

**原书位置：** §3.3–3.4，PDF121–129。

## 09. traits 萃取

用模板接口统一取得型别关联信息；类迭代器可有内嵌型别，原生指针则由特化适配。

**容易混淆：** 不是运行时RTTI，也不是要求所有类型继承公共基类。

**原书位置：** §3.4，PDF124–126。

## 10. 偏特化 partial specialization

在更受限制的一类模板参数上提供仍然带参数的定义，例如T*形式。

**容易混淆：** 不是只能把某个参数替换为固定具体型别；也不要把类模板偏特化直接当函数重载。

**原书位置：** §3.4，PDF124。

## 11. 迭代器类别 iterator_category

把输入、输出、前向、双向及随机存取等能力分类，算法按其最低需求选择实现。

**容易混淆：** 类别的强化关系不是容器类的继承关系；可写性还需单独核对，不可因类别够强就修改const对象。

**原书位置：** §3.4.5，PDF129–134。

## 12. 标签分派 tag dispatch

把类别或真假性质编码成型别标签，通过重载决议选择合适的操作实现。

**容易混淆：** 它不同于运行时if再检查类型；标签也不能凭空证明对象满足声称的能力。

**原书位置：** §3.4.5，PDF130–140。

## 13. SGI __type_traits

原书的SGI私有模板，用真假标签描述trivial构造、复制、赋值、析构等性质以辅助分派。

**容易混淆：** 它不是iterator_traits；也不是可对任意类擅自声明真值以跳过语义操作的许可。

**原书位置：** §3.7，PDF140–149。

## 14. size 与 capacity

vector的size计已构造元素，capacity计既有储存可容纳的元素；由start/finish/end_of_storage区分。

**容易混淆：** 有备用容量不代表这些位置已构造对象；clear后size为0不推出容量为0。

**原书位置：** §4.2.4–4.2.6，PDF155–164。

## 15. deque分段连续空间

元素分别放在多个缓冲区中，迭代器封装跨段运算，使用者仍可按逻辑序列访问。

**容易混淆：** 逻辑随机存取不等于一块连续数组；缓冲区单位要按源码核验，不能仅信32bytes注释。

**原书位置：** §4.4.1–4.4.4，PDF180–187。

## 16. deque的map与node

deque的map是缓冲区指针的控制表，node在此语境指其表项；迭代器node指向控制表位置。

**容易混淆：** 不要把它当关联式std::map，也不要混淆链表的元素节点和这里的缓冲区控制表项。

**原书位置：** §4.4.2–4.4.4，PDF181–187。

## 17. heap与隐式表述

完全二叉树按序列索引表述，heap性质限制父子优先关系；算法在给定区间重排。

**容易混淆：** heap不是本书的独立容器；一个堆也不是整体有序序列；1-based示意索引不同于SGI实际0-based公式。

**原书位置：** §4.7.1–4.7.2，PDF209–217。

## 18. RB-tree 红黑树

具颜色与黑高约束的二叉搜索树，插入修复用变色及旋转维持约束；原书以之承载有序关联容器。

**容易混淆：** 红黑不变量不同于AVL高度差条件；原书采用RB-tree不证明所有标准库都必须采用相同结构。

**原书位置：** §5.2，PDF246–270。

## 19. hashtable 散列表

由散列值选择表项，再处理碰撞的关联储存；原书SGI实现采用开链法。

**容易混淆：** 平均表现不等于任何输入下常数保证；哈希遍历次序不是键排序。

**原书位置：** §5.7，PDF285–307。

## 20. bucket 与开链 separate chaining

一个bucket可关联多个冲突节点，SGI通过单链串起它们；控制表大小与节点总数不同。

**容易混淆：** bucket_count不等于size；空桶也占控制表位置，碰撞不表示键相等。

**原书位置：** §5.7.1–5.7.2，PDF291–294。

## 21. 逻辑新尾与remove/unique

算法把有效元素压到前缀，并返回新尾以表示结果范围；容器缩短须另行执行适用的删除操作。

**容易混淆：** 算法名称remove不表示销毁节点或缩小size；unique仅折叠相邻重复群。

**原书位置：** §6.7.1，PDF395、409。

## 22. 质变与非质变算法

书中按算法是否改变所操作元素分类，但明确承认for_each所调用的仿函数可改变元素。

**容易混淆：** 分类名不能代替可调用对象及引用参数分析；PDF469–470的简化描述要结合PDF330理解。

**原书位置：** §6.1.3–6.1.4，PDF329–330。

## 23. 仿函数 functor / function object

通过对象的operator()提供可调用操作，作为算法策略参数；原书进一步以关联型别支持旧式配接。

**容易混淆：** 不只是一段普通函数；可调用与符合旧式unary_function/binary_function配接协议要分别核对。

**原书位置：** 第7章，PDF453–457。

## 24. 配接器 adapter

包装既有组件并改变其暴露接口：容器配接器限制操作，迭代器配接器改变访问/写入，函数配接器调整调用。

**容易混淆：** 不是所有配接都只是改名字；插入迭代器把赋值变插入，逆向迭代器还改变位置关系。历史适配器的现代可用性另查目标版本。

**原书位置：** §8.1–8.4，PDF465–500。
