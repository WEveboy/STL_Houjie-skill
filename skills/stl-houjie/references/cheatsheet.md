# 决策规则速查 — STL源码剖析

| 能力 | 一句话规则 |
|---|---|
| 从现象回到源码的版本化阅读 | 客户端观察只能说明某次运行发生了什么。 |
| 把原始储存与对象生存期分开核验 | 容器需要预留尚无对象的空间，所以allocate的容量与已构造对象数是两个量。 |
| 推演SGI小区块分档与补池 | 该版SGI以字节数选择配置层。 |
| 按迭代器能力检查traits与分派 | 迭代器屏蔽了容器布局，却仍须向算法提供所指类型、距离类型与能力。 |
| 以size/capacity和生存期推演vector | SGI vector的start、finish、end_of_storage分别界定起点、活元素尾和储存尾。 |
| 按节点不变量追踪list和slist | 链表移动区间首先改变连接，而不是逐个搬移元素值。 |
| 推演deque跨缓冲位置 | deque把逻辑随机存取映射到分段缓冲，map在此是缓冲区指针表。 |
| 保持heap不变量并区分配接器操作 | heap利用数组表示树形次序，最大堆只要求父节点不小于孩子，不要求整个数组有序。 |
| 核对有序树、键与比较等价 | 二叉搜索顺序只能决定向哪边找，平衡不变量才限制最坏高度。 |
| 把哈希定位、相等与重散列分开 | 哈希值先选桶，相等谓词再在碰撞链中判断键。 |
| 复制前核对目标生存期与重叠方向 | copy向目标位置赋值，本身不创建一个更大的容器。 |
| 把remove和unique的逻辑尾转为容器操作 | 算法只拿到范围，通常不能调用未知容器的erase。 |
| 检查有序范围的边界与多重集合规则 | 有序算法依赖相同的比较关系，不依赖容器名字。 |
| 按所需次序选择排序、选择与归并 | 全排序、前k个有序、固定秩和合并两段有序序列是不同任务。 |
| 跟踪数值折叠与函数对象状态 | 数值算法的初值与传参方向会决定结果。 |
| 把迭代器赋值、方向和流副作用写清 | 插入迭代器把赋值转成push或insert，因此copy可以让容器增长。 |
| 将绑定和函数合成展开成表达式 | 绑定先储存参数，调用时再把输入填入剩余位置；非交换运算让绑定第一或第二参数的差别显现。 |
| 在合法范围内推演逆转、旋转和排列 | reverse改变整个方向，rotate交换两个相邻区段且保留各段内部次序，next_permutation按比较器定义寻找相邻字典序排列。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
