# 上传与发行流程

参照“Boolean-vector-research-skill生成”项目的上传流程，面向本项目调整。

1. 核对目标 `WEveboy/STL_Houjie-skill`、写权限及远端最新状态。空仓库在交付准备完成后初始化。
2. 只发布 README、维护说明、原创精读与来源记录、仓颉 Bundle、编译 Skill、原创程序、测试、范例、CI、TeX 和最终教程 PDF。`reading/`、原书、整章转写、临时盲测目录、构建缓存不进入仓库。
3. 运行仓颉格式/引用校验、能力实际任务评测、C++ 编译实验、工具及安装器测试。DSH 适配器契约测试单独记录，不能代替真实付费模型会话。重编译教程并渲染检查。
4. 发布前再次读取远端 HEAD；对已有分支用 SHA 租约更新，保留其他人的文件。不强推。提交 YAML 工作流前解析并核对含冒号的表达式。
5. 上传后核对提交、关键文件与 CI。第一版以 `release: first edition` 提交触发双系统验证和 `edition-v1.0.0` Release；已有同名 Release 时停止，不能覆盖历史资产。
6. Codex ZIP、DeepSeek Harness TGZ/ZIP、源码 ZIP、教程 PDF 与 SHA256SUMS 由同一份 Skill 生成。打包后解压执行烟测，上传后下载重算 SHA256。安装器不能静默覆盖已有 Skill。
7. 保存来源边界、提交 SHA、测试结果、Release URL、资产哈希与待办。哈希仅检测内容一致性，不证明来源身份或程序正确性。

首次发布不自动安装到作者机器。用户可按教程选择安装位置。后续改动继续沿用此流程。
