# 来源、版本与核查边界

## 原书

主来源：侯捷《STL源码剖析》，用户提供的简体中文扫描版，542 个 PDF 物理页。文件 SHA256：`0e18999593897abd76fb368b9de4de9914175a255f69673e4acfb6152465702d`。PDF535 内嵌 General Information 记“2002年06月第1版”，这是文件自带书目信息，尚未与版权页独立核实。正文使用 SGI STL / Cygnus GNU C++ 2.91.57。

535 页含扫描图，已用 Windows.Media.Ocr（zh-Hans-CN）制作本地检索底稿；其余7页为原生文字的书目信息与目录，另行抽取。文字识别不等于代码审计。定位统一用 1-based PDF物理页；插入广告导致它与印刷页之间不存在全书统一偏移。

公开内容是原创解释、短引文及原创验证程序。扫描件、页图、整章文本和完整OCR不随项目发布。八章的框架、机制与条件进行结构扫描，对入选能力的关键依据作针对性回读；这不表示逐行验证了整本书的所有代码和每个历史编译器分支。

## 三类陈述

1. **原书实现事实**：8-byte分档、128-byte阈值、SGI vector增长、deque map与缓冲区、红黑树和哈希底层等，仅在指定版本范围内成立。
2. **本项目教学模型与原创实验**：Python仅推演输入给定的模型；C++实验编译当前机器的标准库。两者都不是书中完整实现的替代，也不是性能基准。
3. **现代语义补充**：以下 C++ 工作草案页面于2026-11-01查阅，解释当前措辞，不冒充2002版原书内容，也不将滚动草案当作已发布ISO标准全文。

现代补充使用公开的 C++ 工作草案：

- [vector.modifiers](https://eel.is/c++draft/vector.modifiers)：插入、重配置和迭代器失效前提。
- [alg.copy](https://eel.is/c++draft/alg.copy)：顺序copy的目标位置、赋值和copy_backward前提；并行重载条件另列。
- [alg.remove](https://eel.is/c++draft/alg.remove)：逻辑尾与未规定尾部值，容器擦除是另一步。
- [alg.foreach](https://eel.is/c++draft/alg.foreach)：可变迭代器允许函数经引用修改元素，函数返回值被忽略。
- [alg.nth.element](https://eel.is/c++draft/alg.nth.element)：最终秩、两侧分区，以及nth==last边界。
- [alg.binary.search](https://eel.is/c++draft/alg.binary.search)：partition前提、对数比较与线性迭代步数的区别。
- [alg.sorting](https://eel.is/c++draft/alg.sorting)：排序、选择、归并与比较关系的要求。

## 已发现的原文疑点

这些是本次提取的发现，不声称构成全书勘误表。

| 位置 | 原书局部表述 | 交付处理 |
|---|---|---|
| PDF184–185 | deque算式32/sizeof(int)=4，却同段及图示按每缓冲8个int计算 | 分开bytes、sizeof(T)、元素数；不复用该算式 |
| PDF189–190 | deque第三模板参数32的文字单位与`__deque_buf_size`源码不一致 | 以该版源码`n!=0`返回n确定元素数，注释冲突保留 |
| PDF295/297 | prime选择文字说“大于”，lower_bound代码实际可取相等 | 模型用大于等于；不靠模糊文字判断边界 |
| PDF333 | 数组尾端外任意位置的指针表述过宽 | 只使用合法范围及one-past，绝不演示越界行为 |
| PDF449 | nth_element括号以“不大于”解释“小于”，重复值边界不清 | 用最终秩和非严格分区契约；不要求两侧有序或严格分开 |
| PDF469–470，对照PDF330 §6.1.4 | 从for_each的分类推出元素内容不能修改，与前章允许修改的说明不一致 | 区分值传参且忽略返回值，与引用参数修改；同书交叉核对，再按现代草案和安全编译实验核验 |

## 尚不声称的能力

本项目不提供完整STL替代库、通用C++静态分析器、自动证明所有容器正确性的工具、微基准结论或针对任意库版本的失效保证。复杂线程、分配器传播、移动异常保证、ranges和concepts等现代专题，需要目标版本的独立来源与测试。宿主路由盲测、工具单元测试、C++编译运行和DSH接口契约测试分别报告。
